Sparktech Laravel Auth v1.2.0

Route architecture update:
- routes/api.php contains the package API endpoints.
- No `api` prefix is hard-coded inside routes/api.php.
- The service provider applies `/api` by default when loading the package API routes.
- The package route file applies `/auth`, resulting in `/api/auth/...`.

Examples:
POST /api/auth/register
POST /api/auth/login
GET  /api/auth/me
POST /api/auth/logout
GET  /api/auth/social/google/redirect
GET  /api/auth/social/google/callback
GET  /api/auth/social/apple/redirect
GET  /api/auth/social/apple/callback
